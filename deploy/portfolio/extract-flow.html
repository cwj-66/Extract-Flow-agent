01 / 产品功能

从一份 PDF，走到可确认的摘要。

自动化完成整理与初步提取，把需要判断的内容留在审阅界面。原文、字段与投递结果能够在同一条任务记录里查找。

01 / UPLOAD

单份与批量上传

上传一份 PDF，或按文件夹批量提交。任务异步执行，工作台展示各份文档的状态与批次进度。

02 / PARSE

正文与图表解析

MinerU 云端解析正文、表格与公式，生成 Markdown；视觉模型补充图像描述，保留结构化文档条目。

03 / EXTRACT

15 个结构化字段

从公司、评级、业绩预测到风险提示，使用固定 Schema 提取研报摘要，便于后续核对与复用。

04 / REVIEW

原文对照与人工修改

并排查看解析原文和提取字段。检查预测、评级与关键观点，修改结果后选择投递群。

05 / DELIVERY

确认后发送飞书

使用数据库中的群配置构建飞书 Card v2。提取完成时停在待确认，投递失败时显示原因并支持重试。

06 / TRACE

历史、导出与审计

按公司、文件名与状态检索任务，下载原始文件，导出已确认发送的字段，查看处理与修改记录。

02 / 处理架构

解析、提取与确认，各有自己的边界。

HTTP 接口负责接收操作，服务层管理任务状态，共享管线执行文档处理。耗时任务进入队列，页面通过轮询获取进度。

任务状态：排队 → 解析 → 提取 → 待确认 → 发送 → 已发送；异常记录为失败。

一条管线，多个入口

CLI、API 与可选 Celery 入口复用同一套 PipelineService 和处理编排。路由层只负责 HTTP 映射，业务逻辑集中在服务层。

把模型计算放在云端

线上调用 MinerU 和 DashScope，服务器负责文件、任务和页面，不常驻加载模型权重。适合与客服 Agent 共用 4GB 服务器。

04 / 容量与稳定性

在 4GB 服务器上，按容量处理。

访客可以浏览与审阅已有任务，新上传的研报进入队列。线上先采用保守并发，让解析与提取有序执行，并为现有服务留出内存。

1份同时执行的研报处理任务
2张每份任务并发描述的图像
15项固定提取字段
4GB与现有项目共用服务器

状态持久化与任务进度

任务保存到数据库，重开页面后仍能查询历史。工作台区分排队、解析、提取、待确认和发送等阶段。

有限内存与云端模型

每个容器设置内存上限；数据库使用较小的缓存，模型计算走云端，上传与解析结果保存在磁盘。

异常提示与重新尝试

模型鉴权失败、解析超时和投递错误会进入任务记录。修正配置后可按界面提示重试，避免失败被当作完成。

复用作品集访问验证

项目介绍和工作台沿用现有作品集登录。数据库与 API 不直接暴露到公网，访问由 HTTPS 反向代理统一转发。

05 / 在线体验指南

用几分钟，走过一份研报的流程。

01

载入样例

进入工作台，点击“载入样例”，查看待确认、已发送和失败场景。样例不调用外部模型，也不发送飞书消息。

02

对照原文审阅

打开待确认任务，核对原文与字段，查看修改后的卡片预览。

03

查看处理记录

浏览任务队列、批次进度与审计记录，了解每一步发生了什么。

04

上传自己的 PDF

尝试真实研报的云端解析。若要投递，请先在“飞书通知”配置自己的群，再确认发送。
